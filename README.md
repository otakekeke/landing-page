## 現行の料金・メッセージ

「減らしたいのは、作業時間だけじゃない。」を軸に、確認・ミス・引き継ぎ・残業等の負担軽減を説明します。

月額利用・運用支援料（税込）＝合意した月間削減時間×共通基準時給2,000円×共通係数3。最低月額なし、0分なら0円。初期費用は導入時に合意した月額の3か月分（税込・初回のみ、月額の前払いではない）。要望による追加機能・対象業務の変更時は変更後全体の削減時間で月額を再計算し、金額・適用開始月を着手前に合意します。標準範囲の追加開発費は月額の増加分×3か月分（税込・その追加につき一度のみ、月額の前払いではない）。月額30,000円→48,000円なら追加開発費54,000円です。対象範囲を着手前に確認し、大規模改修等は別途見積もりとします。係数3は3倍の効果や人件費回収の保証ではありません。

## ビルド・検証

Node.jsで実行します。ビルドと静的テストはNode標準ライブラリのみを使用し、追加パッケージのインストールは不要です。

```sh
npm run build
npm run check:generated
npm test
```

生成元とHTMLの一致、全13HTMLのローカルリンク・アンカー、共通ナビ、重複ID、旧料金・意図しない計測タグ、月額・初期費用の計算の境界値、追加開発費の共通式・増額／据置／減額時の計算例を検証します。法的妥当性、全ブラウザーでの見た目、外部フォームの動作を保証するテストではありません。

ローカルプレビュー例（プロジェクト直下で実行）：

```sh
python -m http.server 4318 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:4318/` を開きます。公開サーバーとして使わないでください。最低限、PCと幅320〜390pxのスマートフォンで全ページの横はみ出し、メニュー、料金表、リンク、入力エラー表示を確認します。
