トップ/ヘルパー募集のホームページとチラシ（川崎市）

川崎市の訪問介護の事業所の方へ

ヘルパー募集のホームページとチラシを、
補助金で作ります。

訪問介護の事業所向けの補助（川崎市・1事業所30万円まで）が決まった時だけ作ります。補助が決まれば、ご負担は実質無料です（お振込の手数料を除く）。決まらなければ、費用はかかりません。

01 / 作るもの

ホームページとチラシを、
ひとまとめで作ります。

ホームページ

  • ヘルパー募集の、1ページのホームページです。スマホで見やすく作ります。
  • 載せること：仕事の内容、働ける曜日と時間、時給、よくある心配への答え、応募の方法。
  • 応募の方法は2つ。電話のボタン（押すと事業所にかかります）と、入力欄（名前と電話番号を書いて送ると、事業所のメールに届きます）。
  • 文章は、お話を伺ってこちらで書きます。

チラシ

  • ホームページと同じ内容の、A4・両面・カラーのチラシを1種類。
  • 1,000枚を印刷して、事業所へお届けします。
  • QRコードを入れます（スマホのカメラで読むと、ホームページが開きます）。
  • 裏面に、利用者・ご家族への案内も入れられます。

料金

30万円（一式）

  • 消費税のご請求はありません。
  • 追加のご請求、月々の費用はありません。
  • お振込の手数料だけ、事業所様のご負担です。

02 / お約束

先にお伝えしておくこと。

  1. 補助が決まった時だけ作ります

    決まらなければ、作りませんし、ご請求もしません。試作を見るのも無料です。

  2. 30万円のほかに費用はかかりません

    追加のご請求も、月々の費用もありません。ご負担は、お振込の手数料だけです。

  3. お支払いは、公開と納品のあとです

    途中でやめても、費用はいただきません。

  4. 申請は、事業所様ご自身で

    申請書を作れるのは、事業所ご本人か行政書士です。書き方は、動画でご案内します。

補助金で戻ります。

30万円をお支払い

公開と納品のあとに、お振込みいただきます。

4月2日まで

事業所様 市

市へ報告

領収書などを付けて出します。付ける物は、こちらでそろえます。

報告のあと

市 事業所様

補助金 30万円

市が金額を確かめたあと、事業所から請求書を出すと、口座に入ります。

  • 補助金が入る日にちは、市から示されていません。それまでは立て替えになります。
  • 補助が決まらなかった時は、お支払いはありません。

04 / ご契約まで

申請して、
市の決定を待ちます。

事業所様にしていただくことは、5つです。

  1. 市へ申請する
  2. 契約書にお名前を書いて、お話を聞かせていただく
  3. 案を見て、直したい所を伝える
  4. お支払い
  5. 市へ報告する

だれがするか：事業所様タケノコ市

  1. はじめに

    お電話で、試作とこの案内を一緒に見ます

    事業所様タケノコ
    • 30分ほどです。事業所様の名前が入った試作を、スマホかパソコンで開いていただきます。開き方は、先にメールでお送りします。
    • その日のうちに、メールで3つお送りします。見積書・制作内容のご説明・申請の手順の動画（約4分）。

  2. 12月28日まで

    市へ申請します

    事業所様
    • 市のホームページにある申請の表（エクセル）に入力して、同じ市のホームページから送ります。
    • 入力するのは、事業所の名前と住所、代表の方、補助金を受け取る口座、「ホームページの制作 30万円」など。動画のとおりに進められます。
    • 分からない所は、お電話ください。同じ画面を見ながらご案内します（入力はご本人にお願いします）。
    • 送ったら、「送りました」とお知らせください。

  3. 申請のあと

    市から、決定のお知らせが届きます

    市
    • 日数は決まっていません。市は、審査して「速やかに」決めるとしています。
    • 待っている間、していただくことはありません。届いたら、お知らせください。

05 / ご契約のあと

作って、公開して、
補助金が入るまで。

  1. 決定が届いたら

    ご契約（契約書）

    事業所様
    • 契約書をお送りします。内容を確かめて、お名前を書いていただきます。印鑑は要りません。
    • ここからが、ご契約です。
    • 市への報告に、この契約書と見積書の写しを使います。

  2. ご契約のあと

    お話を伺います（お電話で1時間ほど）

    事業所様タケノコ
    • ご契約から1週間以内に、日を決めてお電話します。
    • 伺うこと：時給、働ける曜日と時間、仕事の内容、資格が要るか、応募の受け方、働いている方の声。聞くことの一覧を、前の日までにお送りします。
    • 写真は、スマホで撮って送っていただくか、1回お伺いして撮ります。写る方には、載せてよいかを事業所様からお聞きください。

  3. お話のあと

    案をお見せします

    タケノコ事業所様
    • お話を伺ってから1週間以内に、ホームページとチラシの案をメールでお送りします。
    • 直したい所を、電話かメールでお伝えください。「ここの言い方を変えたい」で十分です。直しは2回までお受けします。

  4. 3月12日まで

    ホームページを公開します

    タケノコ事業所様
    • 誰でも見られるようにします。ホームページの住所は「事業所名.takenokonoko.com」の形です。置いておく費用はかかりません。
    • 応募が届くかを、一緒に試します。入力欄から試しに送って事業所のメールに届くこと、電話のボタンでかかることを確かめます。
    • 今のホームページがある場合は、そこに「ヘルパー募集はこちら」の入口を足します。管理している会社さんへお願いする文は、こちらで用意します。

  5. 3月12日まで

    チラシが届きます

    タケノコ
    • 1,000枚を、宅配で事業所へお届けします。
    • チラシの原稿もお渡しします。増し刷りに使えます。
    • 配る作業（ポストへの投函など）は含みません。

  6. 3月19日まで

    お支払い

    事業所様
    • 納品書と請求書をお送りします。請求書に書いた口座へ、30万円をお振込みください。
    • 入金を確かめた日に、領収書をお送りします。
    • 市の決まりで、3月31日までにお支払いが終わった分だけが補助の対象です。

  7. 4月2日まで

    市へ報告します

    事業所様
    • 市の報告の表（エクセル）に入力して、市のホームページから送ります。手順の動画をお渡しします。
    • 一緒に送る物は、こちらでそろえてお渡しします。見積書・契約書・領収書・納品書の写しと、ホームページの画面の写し・チラシ。
    • 領収書などは、事業所でとっておいてください。

  8. 報告のあと

    補助金が入ります

    市
    • 市が報告を確かめて、金額のお知らせを送ります。
    • 事業所から市へ請求書を出すと、事業所の口座に30万円が入ります。請求書の出し方もご案内します。
    • 入る日にちは、市から示されていません。

  9. そのあと

    公開のあと

    タケノコ
    • ホームページは、そのまま残ります。費用はかかりません。
    • 公開から3か月は、文字と写真の入れ替えを無料でお受けします（時給・曜日・電話番号など）。そのあとは、1回ごとにお見積りします。
    • 見られない・応募が届かないなどの不具合は、お知らせください。無料で直します。
    • 公開の1か月後に、応募があったかを伺います。

06 / もしもの時

こういう時は、こうします。

補助が決まらなかった時
作りません。費用はかかりません。
決定が遅れて、3月31日までに終わらないと分かった時
作る前にお伝えします。作らない場合、費用はかかりません。
途中でやめたくなった時
いつでもやめられます。費用はいただきません。決定のあとにやめる時は、市へ取り下げの届けが要ります（出し方は市の窓口へ）。
申請や報告で分からない時
タケノコへお電話ください。補助の決まりそのものは、川崎市の窓口（高齢者事業推進課 044-200-2666）が答えます。
ホームページを、ほかへ移したくなった時
ホームページの中身（文章と写真）は、公開の時にまとめてお渡しします。ほかの会社の置き場へ移せます。

07 / ご確認いただきたいこと

ご確認いただきたいこと。

  • 申請書を作れるのは、事業所ご本人か行政書士です。タケノコは申請書を作りません。お渡しするのは、手順の動画・見積書・制作内容のご説明です。
  • タケノコは民間の事業者です。市の窓口や、市から頼まれた事業者ではありません。
  • 補助は、市の予算の範囲内です。予算に達すると受けられないことがあります。交付が決まることをお約束するものではありません。
  • 対象は、訪問介護・定期巡回・夜間対応型の事業所です。内容は、ヘルパーの募集と、利用者・ご家族への案内に限ります。
  • このページの日付と金額は、令和8年度の川崎市の補助（川崎市内の事業所）の場合です。
