嶽ノ子の姿勢

介護現場の業務は、毎日の中で自然に回っているため、言葉だけで説明するのが難しいことがあります。

「シフトを組むときの感覚」「申し送りで使う独特の言い回し」「ベテランだけが知っている判断基準」── これらは、すべてを言葉にするには大きな手間がかかります。

嶽ノ子では、最初から細かい仕様を決めていただくのではなく、今使っている紙・Excel・帳票・シフト表などをこちらで読み解いて、必要な仕組みを一緒に整理します。

最後は人が判断します。シフト案・集計案などは自動で出し、管理者が確認・調整できる形に。

線引きで整理。

追加要望は自然なもの。不具合／仕様内調整／仕様変更／追加開発に分けて、誠実に整理します。

RULE 07

運用に乗るまで、
支援します。

理念
— PHILOSOPHY

介護職は、
社会の「心」を
支える仕事。

社会を動かしているのは、企業でも制度でもなく、毎日を生きる人たちです。その人たちが安心して働き、暮らし続けられるのは、「大切な人が守られている」という確信があるから。

介護は、人対人の究極の仕事であり、AI時代になっても最後まで残る崇高な仕事です。その貴重な人材を、誰でもできる事務作業や、アナログな反復作業に費やさせたくない。

ご家族の心が安定すれば、家庭が安定し、働く人が安定し、社会が固まる。介護職は、社会を支えている。その事実と理由を、ITで証明し、強化する ── それが嶽ノ子の存在理由です。

完全自動を保証するものではありません。希望休・勤務条件・人員配置をもとにシフト案を作成し、最後は管理者が確認・調整する形を基本としています。完全自動を目指すと、現場の判断や個別事情が反映できなくなるためです。
Q 今使っているExcelシフトをそのまま使えますか？ ＋
現在のExcelを確認したうえで、使い慣れた形式に近い出力を設計します。ただし、すべてのレイアウトを完全再現する場合は追加費用が発生することがあります。事前にどこまで再現するか、どこを変えるかを合意してから進めます。
Q 希望休の回収もできますか？ ＋
できます。スタッフがスマホやフォームで希望休を入力し、管理者が一覧で確認できる形にできます。紙やLINEで集める手間を減らせます。
Q 職員の相性や家庭事情も自動で考慮できますか？ ＋
一部は条件として登録できますが、すべてを自動判定することはおすすめしません。人間の判断が必要な内容は、管理者が確認・調整できる形にします。最終的な「組ませない」「単独夜勤にしない」などの判断は、現場側に残します。
Q 夜勤や早番・遅番にも対応できますか？ ＋
勤務区分として設定できます。施設ごとの勤務条件・夜勤明けの扱い・連勤制限を確認したうえで対応範囲を決めます。
Q 人員配置基準の確認もできますか？ ＋
設定した条件に対して、不足や確認漏れを警告することは可能です。ただし、法令判断や最終判断は事業所様側でお願いします。嶽ノ子は人員配置基準の代行判断は行いません。
Q 何名くらいの職員まで対応できますか？ ＋
ライトプランは職員30名程度、スタンダードは50名程度までを目安にしています。それ以上の規模や複数事業所の場合は、法人・複数事業所プランで対応します。
Q 導入までどのくらいかかりますか？ ＋
シンプルなシフトであれば、2〜4週間程度で試せる形にできます。夜勤・複数勤務区分・複雑な配置条件がある場合は、1〜2か月程度かかる場合があります。
Q シフト以外の業務も相談できますか？ ＋
はい。送迎管理・月次集計・記録チェック・申し送り・在庫管理・家族連絡などの紙・Excel業務もアプリ化できます。範囲に応じて固定価格のプランから個別見積りまで、合うものをご提案します。
Q 送迎管理はどこまで対応できますか？ ＋
利用者・送迎ルート・時間の管理、変更履歴の記録、職員間での最新版共有、印刷や一覧確認の効率化まで対応できます。標準アプリ（初期 ¥500,000／月額 ¥30,000）でカバーできる範囲が中心です。GPS追跡や自動ルート最適化など高度なものは個別見積りになります。
Q 月次集計や報告書作成は自動化できますか？ ＋
毎月のExcel集計、転記作業、報告書テンプレート出力までを仕組み化できます。現在使っているExcelや帳票を見せていただいたうえで、どの部分を自動化し、どの部分を人の確認に残すかを一緒に整理します。標準アプリでカバーできることが多いです。
Q 何を作りたいか、うまく説明できなくても大丈夫ですか？ ＋
大丈夫です。介護現場では、必要な仕組みを最初から言葉にするのは難しいものです。現在使っている紙、Excel、帳票、過去データ、実際の作業の流れを見ながら、こちらで業務を整理し、アプリ化する内容を提案します。お客様に仕様書を書いていただく必要はありません。
Q 現場に来て業務を見てもらえますか？ ＋
はい。必要に応じて現場に伺い、実際の作業、帳票、Excel、確認作業の流れを確認します。現場の方に長い仕様書を作っていただくのではなく、こちらが現場を見て整理します。遠方の場合はオンラインと現場訪問を組み合わせます。
Q 使ってから追加したいことが出た場合はどうなりますか？ ＋
追加のご要望は自然に発生するものと考えています。内容を確認し、「不具合の修正」「月額内の軽微な調整」「別途お見積りが必要な変更」に分けて整理します。月額内の軽微な調整は保守範囲で対応し、新機能追加や業務の流れの変更は事前にお見積りします。お客様を責めるような対応はしません。
Q 既存の介護ソフトとは何が違いますか？ ＋
請求や記録などの標準業務は既存ソフトが得意です。嶽ノ子では、既存ソフトでは対応しきれない紙・Excel・独自帳票・現場ごとの確認作業・集計作業などを、施設に合わせてアプリ化します。既存ソフトと併用することを前提に設計します。
Q 契約後に費用が膨らむことはありませんか？ ＋
アプリ商品は固定価格でご提示します（紙・Excel改善パック ¥100,000／小規模アプリ ¥200,000／標準アプリ ¥500,000／複雑ロジック対応 ¥800,000〜）。表示価格で対応できる範囲を事前に明確にし、追加費用が発生する場合は作業前に必ず内容と金額をご説明します。合意のないまま費用が増えることはありません。
Q 「小さな修正」の範囲はどこまでですか？ ＋
月額に含まれる「小さな修正」とは、文言変更、表示順変更、軽微な項目名変更など、既存仕様の範囲内の調整を指します。新機能追加、帳票追加、ロジック変更、業務フロー変更は別途お見積りとなります。境界が曖昧な場合は、事前に整理してお伝えします。
Q 導入までどのくらいかかりますか？ ＋
無料相談・簡易診断 →（数日〜1週間で）商品プラン提案・お見積り → 業務整理＋設計＋試作 → 開発・試用・本番導入 → 月額サポート。紙・Excel改善パックなど小規模なものは2〜4週間、標準アプリは1〜2か月、複雑ロジック対応は2〜4か月程度が目安です。業務の規模や複雑さによって変わります。
Q 個人情報を扱う場合、セキュリティ・法令は大丈夫ですか？ ＋
介護に関する情報は要配慮個人情報を含み得るため、特に丁寧に扱います。Google Workspaceを前提とした運用構成、アクセス権限設計、操作記録、データ保存・委託先監督の方針を、導入前に書面でお伝えします。開発時の実データ利用は原則匿名化、または別環境で扱います。
Q 小さいツールから始めて、後で広げられますか？ ＋
はい。まず1つの業務から始めて、効果を確認してから他業務へ広げる進め方が基本です。最初の確認で全体像を把握しているため、後から広げやすい設計にしています。
Q 解約後、アプリやデータはどうなりますか？ ＋
月額契約終了後は、保守・修正・問い合わせ対応・継続利用環境の管理は対象外となります。お客様のGoogle Workspace内に保存されたデータはお客様のものとして残ります。必要に応じてCSV等でのデータエクスポートにも対応します。Google Workspace内データの扱いは契約時に書面で明確にお伝えします。
Q Google Workspace を契約していないと使えませんか？ ＋
Google Workspaceをお使いの場合は、既存環境を活用できます。未導入の場合は、必要なアカウント数・Google側の月額利用料・管理方法を事前にご説明します。当社側の追加サーバー費用はかかりませんが、Google側の利用料（1ユーザー月¥680〜程度）は別途必要です。
Q カイポケなど既存介護ソフトと自動連携できますか？ ＋
既存ソフトとの連携は、CSV出力・取り込み・手動運用を含め、可能な範囲で設計します。自動連携を保証するものではありません。多くの既存介護ソフトはAPIが公開されておらず、契約上の制約もあるため、現実的にはCSV出力やコピーペースト運用で対応することが多くなります。事前に対象ソフトの仕様を確認してご提案します。
Q 解約はできますか？ ＋
はい、いつでも解約できます。14日前にご連絡いただければ、14日経過後に解約が成立します。既に支払った費用の返金はありません。解約後は保守・修正・問い合わせ対応の対象外となります。お客様のGoogle Workspace内に保存されたデータはお客様のものとして残り、必要に応じてCSV等でエクスポートできます。アプリの継続利用環境の管理は対象外となります。
